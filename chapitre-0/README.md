# Chapitre 0 — Penser comme un attaquant

Ce chapitre n'a pas de code de départ : les dix exercices sont des livrables
écrits (cartographie, classement OWASP, diagnostics), pas du code à compléter.
Chaque dossier contient un `README.md` de rappel ; l'énoncé complet reste le
document Word `XXXX-exercice.docx`.

| Exercice | Niveau | Titre | Dossier |
|---|---|---|---|
| 0101 | 1 Découverte | Vulnérabilité, exploit ou impact ? | `exercices/0101/` |
| 0102 | 1 Découverte | Le cadre légal, vrai ou faux | `exercices/0102/` |
| 0201 | 2 Application | Installer ton terrain d'entraînement | `exercices/0201/` |
| 0202 | 2 Application | Classer une faille dans le bon référentiel | `exercices/0202/` |
| 0301 | 3 Consolidation | Cartographier SenShop | `exercices/0301/` |
| 0302 | 3 Consolidation | Écrire un diagnostic en quatre lignes | `exercices/0302/` |
| 0411 | 4 Approfondissement | Le rapport Veracode, lu et discuté (concept externe) | `exercices/0411/` |
| 0402 | 4 Approfondissement | Un scénario, deux référentiels, une priorité | `exercices/0402/` |
| 0501 | 5 Expert | L'audit préliminaire complet de Juice Shop | `exercices/0501/` |
| 0502 | 5 Expert | La charte de sécurité de ta propre application | `exercices/0502/` |

Rappel du cadre légal du chapitre : toute manipulation offensive se fait
exclusivement sur des applications fournies (OWASP Juice Shop en local, ou un
projet que tu as toi-même écrit), jamais sur un système qui ne t'appartient
pas.
